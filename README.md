# 📘 Les 3 Hackeurs – Aventure Git Narrative

Bienvenue dans notre projet pédagogique : une aventure narrative collaborative dans l’univers de GitHub Monde.

Trois étudiants — Dylan, Enes, et Yanis — ont traversé six chapitres pour découvrir les mystères du Repository Suprême.  
Chaque branche Git correspond à un chapitre écrit, développé puis fusionné dans une branche centrale `develop`.

---

## 🧱 Structure du dépôt

- `introduction.txt` : Point de départ narratif du projet
- `chapitre1.txt` → `chapitre6.txt` : Contenu de chaque chapitre
- `images/schema_git.png` : Schéma des branches Git du projet
- `README.md` : Ce fichier

---

## 🔁 Organisation Git

- Branche centrale : `develop`
- Branches parallèles : `chapitre1` à `chapitre6`
- Chaque branche a été créée, modifiée, puis fusionnée manuellement

---

## 👨‍💻 Membres du groupe

| Prénom | Rôle | Poste utilisé |
|--------|------|----------------|
| Enes   | Git init + Chapitres 1–2 | PC 1 |
| Dylan  | Chapitres 3–4 | PC 2 |
| Yanis  | Chapitres 5–6 + schéma final | PC 3 |

Chaque membre a utilisé **son propre compte GitHub** et un **token personnel** pour signer ses commits.

---

## 🗺️ Objectif du projet

- Apprendre Git en profondeur
- Travailler en branches et comprendre les fusions
- Créer une narration continue à travers un dépôt
- Utiliser des outils collaboratifs (clonage, merge, push, etc.)

---
